# 网页翻译助手

免费、免登录、免 API Key 的浏览器网页翻译扩展，**专为装不了官方商店插件的用户打造**——Chrome 商店在国内无法访问，Edge 商店的翻译插件也时常失效/下架，这个扩展不依赖任何商店，手动加载即可使用。

Edge 与 Chrome 通用（同一文件夹，两个浏览器可同时加载）。目标语言固定为**简体中文**（外语 → 简中）。

## 功能

- **整页翻译**：点击扩展图标 → 「翻译此页」，译文以蓝色跟在原文后面（双语对照，可切「仅看译文」），可一键还原
- **划词翻译**：用鼠标选中网页上的文字，自动弹出翻译小窗（输入框里的选中文字也支持）
- **右键菜单**：选中文字后右键 → 「翻译选中文字」
- **智能引擎**：Google / 必应同时发出、谁先成功用谁的竞速模式，自动适应代理开/关，失败自动降级 MyMemory，无需手动干预
- **自动翻译**：弹窗里勾选「打开此网站时自动翻译」，该网站今后打开即翻
- **动态跟进**：翻译后新加载的内容（懒加载/无限滚动）自动补翻
- **两级缓存**：还原后重翻秒回；后台缓存随浏览器会话保留

## 安装

### 第一步：下载

点本页面绿色的 **Code** 按钮 → **Download ZIP** → 解压到电脑上**固定的位置**（比如 `D:\extensions\`，别放在下载文件夹里随手清掉的地方，删掉文件夹扩展就没了）。

### 第二步：加载到浏览器

**Edge：**

1. 地址栏输入 `edge://extensions` 回车
2. 打开左侧「开发人员模式」开关
3. 点「加载解压缩的扩展」→ 选择解压出来的 `web-translator` 文件夹
4. 建议点一下工具栏的拼图图标 🧩，把「网页翻译助手」固定到工具栏

**Chrome：**

1. 地址栏输入 `chrome://extensions` 回车
2. 打开右上角「开发者模式」开关
3. 点「加载已解压的扩展程序」→ 选择解压出来的 `web-translator` 文件夹
4. 同样建议固定到工具栏

## 使用

| 操作 | 效果 |
|---|---|
| 点工具栏图标 → 翻译此页 | 整页双语翻译；可反复点，一直是中文；想回原文点「还原」 |
| 鼠标选中文字 | 弹出划词翻译小窗 |
| 右键 → 翻译选中文字 | 同上 |
| Esc / 点击空白处 / 滚动 | 关闭划词小窗 |

## 翻译引擎说明

| 引擎 | 需要代理 | 特点 |
|---|---|---|
| Google | ✅ 需要开代理 | 质量最好；共享代理节点 IP 偶尔被限流，会自动换备用通道或切必应 |
| 必应 | 开关代理都行 | 大模型翻译，质量好；自动在 cn / 国际站之间选当前网络能通的那个 |
| MyMemory | ❌ 免代理 | 兜底；每日约 5000 字免费额度 |

- 默认「智能」模式：Google 和必应同时发请求、谁先成功用谁——开代理、关代理、切换节点都自动适应，完全无感
- 也可在弹窗里手动指定引擎

## 常见问题

- **翻译失败 / 一直转圈**：翻译走的是第三方公开免费接口（见下方说明），接口偶尔变动会导致暂时失效，等待本仓库更新即可
- **浏览器内部页面**（如 edge://settings、Chrome 商店页）无法注入脚本，属于浏览器安全限制
- **MyMemory 提示额度用完**：每天约 5000 字（按 IP），第二天恢复，或切换其他引擎
- **更新版本**：重新下载 ZIP 解压覆盖旧文件夹，再到扩展管理页点「重新加载 ↻」
- 修改了插件文件后，同样需在扩展管理页点「重新加载」↻

## 说明与免责

- 翻译由 Google / 必应 / MyMemory 的**公开免费接口**提供（非付费官方 API），这些接口随时可能变动导致暂时失效，届时需等待本仓库适配更新
- 扩展完全在本地运行，**不收集、不上传任何数据**
- 目标语言仅支持简体中文
- 本项目仅供学习与个人使用交流
